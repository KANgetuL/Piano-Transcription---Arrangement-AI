## 1. 产品概述

### 1.1 产品名称

PianoTrans AI（钢琴智能扒谱与改编工具）

### 1.2 产品定位

一款面向钢琴爱好者、编曲人、音乐教师及黑乐谱创作者的全功能扒谱工具，以“AI驱动、简单易用、多风格适配”为核心，提供PC端（带可视化UI）及网页端（后续扩展）服务，支持流行、电子、古典音乐一键生成钢琴谱、黑乐谱，实现音频到乐谱的全自动转换，同时支持乐谱编辑、导出与预览。

### 1.3 核心目标

- 降低扒谱门槛，让非专业用户也能快速获取高质量钢琴谱

- 实现多风格智能改编，满足不同用户的演奏、创作需求

- 提供可视化UI操作，简化操作流程，提升用户体验

- 支持PC端稳定运行，后续扩展网页端，实现多端适配

- 优化AI模型运行效率，适配不同配置电脑，降低使用门槛

### 1.4 目标用户

| 用户类型           | 核心需求                                                     | 使用场景                                    |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------- |
| 钢琴爱好者（核心） | 快速获取喜欢歌曲的钢琴谱，无需人工听谱；支持简单编辑，适配自身演奏水平 | 在家练习、自学钢琴，获取热门歌曲钢琴版乐谱  |
| 编曲人/音乐创作者  | 多风格改编，快速生成钢琴伴奏谱；支持黑乐谱创作；导出多格式文件用于后期编辑 | 音乐创作、编曲适配、黑乐谱特效制作          |
| 音乐教师           | 快速生成练习谱，适配学生水平；支持修改乐谱难度，批量导出教学用谱 | 钢琴教学、练习任务布置                      |
| 黑乐谱创作者       | 一键生成乐理合理的黑乐谱，支持自定义音符密度、声部数量       | 黑乐谱制作、视频特效配乐（如B站黑乐谱视频） |

### 1.5 产品范围

- 当前核心：PC端（Windows、MacOS）带可视化UI，实现全部核心扒谱、改编、导出功能

- 后续扩展：网页端（适配主流浏览器），实现核心功能同步，支持在线扒谱、云端存储

- 暂不涉及：移动端（手机、平板）、专业级编曲功能（如多轨混音）、付费增值服务

## 2. 功能需求（核心优先级：P0必做，P1重要，P2可选）

### 2.1 通用基础功能（PC端+网页端通用，P0）

#### 2.1.1 文件上传与管理

- 支持上传音频文件格式：MP3、WAV（优先），后续扩展FLAC、AAC（P1）

- 支持两种上传方式：本地文件选择、拖拽上传（PC端）；本地文件选择、URL粘贴（网页端）

- 上传后显示文件信息：文件名、文件大小、时长、格式，支持文件重命名、删除、替换

- 支持批量上传（最多同时上传5个文件，P1），显示批量上传进度

#### 2.1.2 扒谱模式选择

- 默认提供5种模式，点击即可选择，实时显示模式说明：
        

  - 普通钢琴谱：默认模式，提取主旋律+基础和弦，适配日常演奏

  - 流行风格：右手主旋律，左手流行柱式/分解和弦，优化节奏适配流行歌曲

  - 电子风格：提取主旋律+低音循环，量化节奏，适配电子音乐特点

  - 古典风格：保留多声部，自动分配左右手，还原琶音、对位法

  - 黑乐谱：超密集音符、多声部叠加，乐理合理，支持自定义密度（P1）

- 支持模式记忆功能，记住用户上次选择的模式，下次打开自动默认

#### 2.1.3 扒谱进度展示与控制

- 实时显示扒谱进度条，标注当前进度（百分比）、剩余时间

- 支持暂停、继续、取消扒谱操作：
        

  - 暂停：暂停当前扒谱进程，保留已处理数据，再次点击继续

  - 取消：终止扒谱进程，删除临时文件，不生成任何输出

- 扒谱完成后，弹出提示框，显示“扒谱成功”，可直接点击“查看乐谱”“导出文件”

#### 2.1.4 乐谱预览

- 扒谱完成后，自动加载乐谱预览界面，支持放大、缩小、拖拽查看

- 支持乐谱播放预览：点击播放按钮，同步显示音符高亮（跟随播放进度），可调节播放速度（0.5x-2.0x）

- 预览界面区分左右手（右手高音区、左手低音区），可单独隐藏/显示左手/右手乐谱（P1）

- 支持预览时跳转至指定小节（输入小节号，快速定位）

#### 2.1.5 乐谱导出

- 支持导出格式：MIDI（.mid）、MusicXML（.musicxml）（P0）；PDF、PNG（P1）

- 导出设置：可选择导出路径（PC端）、文件名自定义、是否导出双手合并谱/分谱（P1）

- 批量导出：支持同时导出多个扒谱完成的文件，统一选择导出路径和格式（P1）

- 导出进度提示，导出完成后提示“导出成功”，可直接打开导出文件夹

### 2.2 PC端专属功能（P0）

#### 2.2.1 可视化UI界面

- 主界面布局（简洁易用，适配1080P及以上分辨率）：
       

  - 顶部导航栏：文件、编辑、设置、帮助、关于

  - 左侧：文件上传区、模式选择区、进度显示区

  - 中间：乐谱预览区（核心区域）

  - 右侧：操作面板（播放、导出、编辑、设置）

- 支持窗口最大化、最小化、还原，适配不同屏幕尺寸

- 支持皮肤切换（默认浅色，可选深色模式，P1），保护视力

- 操作提示：鼠标悬浮在按钮上，显示功能说明；首次使用时，弹出引导教程（P1）

#### 2.2.2 乐谱简单编辑（P0）

- 基础编辑：点击乐谱音符，可修改音符音高、时值（四分音符、八分音符等）

- 和弦编辑：支持添加/删除和弦，修改和弦类型（大三、小三、七和弦等）

- 节奏调整：支持整体节奏加快/减慢，不改变音高

- 保存编辑：编辑后可保存为新的乐谱文件，覆盖原文件或新建文件

#### 2.2.3 本地设置与管理

- 模型设置：可选择模型运行模式（快速模式：占用资源少，速度快；高精度模式：识别更准，速度稍慢）

- 路径设置：默认上传/导出路径设置，可自定义修改，支持记住上次路径

- 缓存管理：可清理临时文件、模型缓存，释放存储空间

- 语言设置：支持中文、英文（P1），默认中文

#### 2.2.4 离线运行（P0）

- 首次运行需联网下载预训练模型（约300-500MB），后续可离线运行，无需联网

- 模型更新提示：当有新模型版本时，联网状态下弹出更新提示，支持手动更新（P1）

### 2.3 网页端专属功能（P1，后续扩展）

- 浏览器适配：支持Chrome、Edge、Firefox等主流浏览器（最新版本），不支持IE

- 云端存储：支持将扒谱完成的乐谱、上传的音频文件保存至云端（免费额度：1GB，P2），可随时查看、下载

- 在线分享：支持将乐谱生成分享链接，发送给他人查看、预览（P2）

- 轻量化操作：适配网页端交互，简化操作流程，无需安装客户端，打开浏览器即可使用

- 进度同步：PC端与网页端登录同一账号，可同步扒谱进度、保存的文件（P2）

### 2.4 高级功能（P2，可选）

- 乐谱难度调整：支持调整乐谱难度（简单、中等、困难），自动修改音符复杂度、节奏难度

- 自定义黑乐谱：支持设置音符密度、声部数量、装饰音类型，生成个性化黑乐谱

- 多轨扒谱：支持生成四手联弹、双钢琴谱（多轨乐谱）

- 音频剪辑：支持对上传的音频进行简单剪辑（截取片段），仅对片段进行扒谱

## 3. 非功能需求（P0必做）

### 3.1 性能需求

- 运行速度：PC端（最低配置）处理3分钟音频，扒谱耗时≤60秒；推荐配置耗时≤30秒

- 响应速度：UI操作（上传、选择模式、预览、导出）响应时间≤1秒，无卡顿

- 稳定性：连续运行1小时无崩溃、无闪退；批量扒谱无异常中断

- 内存占用：运行时内存占用≤8GB（最低配置），≤12GB（推荐配置）

### 3.2 兼容性需求

- PC端系统：支持Windows 10/11（64位）、MacOS 10.15及以上（64位），兼容Intel、M1/M2芯片

- 网页端浏览器：支持Chrome 100+、Edge 100+、Firefox 95+，分辨率≥1366×768

- 文件兼容性：导出的MIDI、MusicXML文件可正常打开（支持MuseScore 4+、Overture 5+）；PDF、PNG导出无乱码、无失真

### 3.3 易用性需求

- 操作流程：核心操作（上传→选择模式→扒谱→预览→导出）不超过5步，无需专业知识

- 提示信息：所有操作结果（成功、失败、警告）均有明确提示，引导用户下一步操作

- 错误处理：当出现文件格式错误、内存不足、模型加载失败等问题时，弹出明确错误提示，并提供解决方案（如“文件格式不支持，请上传MP3/WAV文件”）

### 3.4 安全性需求

- PC端：不收集用户隐私信息，本地文件仅存储在用户指定路径，不自动上传云端

- 网页端：用户上传的文件、保存的乐谱仅用户可查看，采用加密存储；不收集用户个人信息（除必要的登录信息，P2）

- 模型安全：使用开源预训练模型，无恶意代码，不获取用户电脑权限（仅获取文件读写权限）

### 3.5 可扩展性需求

- 功能扩展：预留接口，支持后续添加新的扒谱模式、导出格式、编辑功能

- 模型扩展：支持模型更新、替换，可适配新的AI模型，提升扒谱精度

- 多端扩展：PC端与网页端架构兼容，后续可快速扩展移动端（P2）

## 5. 约束条件

- 技术约束：基于Python开发，依赖开源AI模型（Demucs、CREPE、Basic Pitch），不可修改模型核心逻辑，仅可进行适配开发

- 时间约束：PC端核心功能需在16周内完成开发、测试并上线；网页端基础功能在PC端上线后8周内完成

- 资源约束：模型文件大小控制在500MB以内，避免占用过多用户存储空间

- 合规约束：不涉及版权问题，用户上传的音频文件由用户自行负责，产品仅提供扒谱工具，不存储、不传播音频文件

## 6. 常见问题（FAQ）

- Q：扒谱精度不够怎么办？A：建议选择“高精度模式”，并上传清晰、无过多杂音的音频文件；扒谱后可通过编辑功能修改音符。

- Q：模型下载失败怎么办？A：检查网络连接，关闭防火墙，重新运行软件；若仍失败，可手动下载模型文件（提供下载链接），放入指定目录。

- Q：导出的乐谱无法打开？A：确保使用MuseScore 4+、Overture 5+等支持的软件；若仍无法打开，重新导出文件，选择不同格式。

- Q：网页端是否需要安装插件？A：不需要，直接打开浏览器即可使用，确保浏览器版本符合要求。
