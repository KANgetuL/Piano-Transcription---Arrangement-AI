# 依赖管理规范（v0.1）

## 依赖分层
- 核心依赖: 数学/音频/模型推理相关，谨慎升级。
- 工具依赖: 日志、配置、CLI，可按次版本升级。
- 开发依赖: 测试、格式化、静态检查，仅开发环境使用。

## 版本策略
- 生产依赖使用明确版本范围，避免无限上浮。
- 每次升级必须记录变更原因与兼容性评估。
- 模型相关依赖升级前必须跑回归测试。

## 安全与许可
- 禁止引入未知许可证依赖。
- 新依赖必须通过基础安全扫描。

## 管理方式
- Python: pyproject.toml 为单一事实来源。
- Node: package.json 为单一事实来源。
- 不允许同类依赖在多个文件重复定义版本。

## 禁止项
- 禁止在业务代码中动态安装依赖。
- 禁止未评估直接升级主版本。
