# Piano Transcription & Arrangement AI

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue) ![License](https://img.shields.io/badge/license-MIT-green) ![Dependencies](https://img.shields.io/badge/dependencies-up%20to%20date-brightgreen)

一款基于 Python + AI 模型的全自动钢琴扒谱工具，支持流行、电子、古典音乐一键生成专业钢琴谱，同时支持生成乐理合理的黑乐谱，无需人工听谱，开箱即用。

## 核心功能

- **多乐器音源分离**：自动拆分人声、鼓、贝斯、钢琴及旋律乐器，精准提取核心主旋律，过滤冗余声部

- **全风格智能适配**：针对流行、电子、古典音乐自动匹配钢琴演奏逻辑（和弦编配、琶音设计、低音伴奏）

- **高精度AI扒谱**：基于谷歌CREPE、Spotify Basic Pitch预训练模型，音高、节奏、节拍识别精度远超传统算法

- **黑乐谱生成**：支持生成超密集音符、多声部叠加的黑乐谱（人类理论无法演奏，但乐理逻辑严谨）

- **标准格式导出**：生成 MIDI / MusicXML 格式，可直接在 MuseScore、Overture 等软件中编辑、导出PDF

## 快速使用

1. 将需要扒谱的音乐文件（支持 MP3、WAV 格式）放入 `input/` 目录

2. 运行主程序，按照终端提示选择模式：
    
3. 终端提示选择扒谱模式：
        

    - 1. 普通钢琴谱（默认）

    - 2. 流行风格改编

    - 3. 电子风格改编

    - 4. 古典风格改编

    - 5. 黑乐谱生成

4. 等待程序运行完成（根据音乐长度，耗时10-60秒）

5. 在 `output/`目录获取生成的 `.mid` 或 `.musicxml` 文件

6. 使用 [MuseScore（免费）](https://musescore.org/) 打开文件，即可编辑、预览、导出PDF乐谱

## 输出格式说明

- **.mid**：MIDI 文件，支持所有编曲软件（如 Cubase、FL Studio）和钢琴演奏设备

- **.musicxml**：标准乐谱交换格式，可直接用 MuseScore、Overture 打开，支持编辑、打印

- 扩展支持：通过 MuseScore 导出为 PDF、PNG 图片、MP3 演奏音频

## 注意事项

- 音频文件建议选择清晰、无过多杂音的版本，扒谱精度更高

- 首次运行时，模型会自动下载（约几百MB），请确保网络通畅

- 黑乐谱为特效谱，仅用于视觉展示或特殊用途，不适合人类实际演奏

- 生成的乐谱可在 MuseScore 中进一步编辑，优化演奏细节
